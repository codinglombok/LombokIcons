## What Makes LombokIcons Different

Most icon libraries converge on the same look — flat strokes on a square grid, differentiated only by weight. LombokIcons introduces **Dimensional Clarity**: every icon is constructed with visual depth through a triple-mode rendering system, all from a single SVG definition.

| Mode | Visual | Use Case |
| ------ | -------- | ---------- |
| **line** | Clean 1.5px strokes | Body text, dense UI, tables |
| **bold** | 2px strokes + filled accents | Navigation, headers, emphasis |
| **duo** | Two-tone (primary + accent layer) | Hero sections, dashboards, CTAs |

The `duo` mode is LombokIcons' signature — the accent color and opacity are controlled entirely via CSS custom properties. No extra SVG files, no sprite swaps, no build step.

### vs Font Awesome / Heroicons / Lucide / Phosphor

- **Not a font** — pure SVG, no `.woff2`, no `@font-face` hacks
- **3 render modes** from one icon definition (line / bold / duo)
- **CSS custom properties** for full theming (`--lf-color`, `--lf-duo`, `--lf-duo-opacity`)
- **Diamond Canon grid** — distinctive centered visual mass vs standard square-grid icons
- **Tree-shakeable** — import only what you use (ESM + CJS)
- **2.2 KB CSS** — entire framework smaller than a single Font Awesome web font
- **Zero dependencies**

## Usage

### Method 1: Data Attributes (Simplest)

```html
<link rel="stylesheet" href="lombokicons/dist/css/lombokicons.min.css">

<i data-lf="home"></i>
<i data-lf="search" data-lf-mode="duo"></i>
<i data-lf="bell" data-lf-mode="bold" class="lf-lg lf-ring"></i>

<script type="module">
  import { replaceIcons } from 'lombokicons';
  replaceIcons(); // auto-replaces all [data-lf] elements
</script>
```

### Method 2: JavaScript Rendering

```js
import { renderIcon } from 'lombokicons';

document.getElementById('icon-slot').innerHTML = renderIcon('star', {
  mode: 'duo',
  class: 'lf-xl'
});
```

### Method 3: Direct SVG (Copy-Paste)

```html
<span class="lf lf-lg">
  <svg viewBox="0 0 24 24" fill="none" stroke="currentColor"
       stroke-width="1.5" stroke-linecap="round" stroke-linejoin="round">
    <path d="M3 10.5L12 3l9 7.5V20a1 1 0 01-1 1h-5v-6H9v6H4a1 1 0 01-1-1z"/>
  </svg>
</span>
```

### Method 4: SVG Sprite

```html
<svg class="lf lf-lg">
  <use href="lombokicons/dist/svg/lombokicons-line.svg#lf-home"/>
</svg>
```

## API

### CSS Custom Properties

```css
:root {
  --lf-size: 1.25em;       /* Icon size — scales with parent */
  --lf-color: currentColor; /* Stroke/fill color */
  --lf-stroke: 1.5;         /* Stroke width */
  --lf-duo: currentColor;   /* Duo accent color */
  --lf-duo-opacity: 0.32;   /* Duo accent opacity */
}
```

### Size Classes

| Class | Size |
| ------- | ------ |
| `lf-xs` | 12px |
| `lf-sm` | 16px |
| `lf-md` | 20px (default) |
| `lf-lg` | 24px |
| `lf-xl` | 32px |
| `lf-2xl` | 48px |
| `lf-3xl` | 64px |

### Stroke Classes

| Class | Weight |
| ------- | -------- |
| `lf-thin` | 1 |
| `lf-normal` | 1.5 |
| `lf-bold` | 2 |
| `lf-heavy` | 2.5 |

### Animations

| Class | Effect |
| ------- | -------- |
| `lf-spin` | Continuous rotation (loading) |
| `lf-pulse` | Opacity pulse (attention) |
| `lf-bounce` | Vertical bounce (notification) |
| `lf-shake` | Horizontal shake (error) |
| `lf-ring` | Bell-like ring (alert) |

All animations respect `prefers-reduced-motion: reduce`.

### Transforms

`lf-rotate-45` · `lf-rotate-90` · `lf-rotate-180` · `lf-rotate-270` · `lf-flip-h` · `lf-flip-v`

### JavaScript API

```js
import { renderIcon, replaceIcons, icons, categoryMap, count } from 'lombokicons';

// Render a single icon as HTML string
const html = renderIcon('home', {
  mode: 'duo',       // 'line' | 'bold' | 'duo'
  size: '2rem',      // CSS size override
  class: 'my-class', // Extra CSS classes
  color: '#e53e3e'   // Color override
});

// Auto-replace all <i data-lf="..."> elements in the DOM
replaceIcons(document.body, 'line');

// Access metadata
console.log(count);                // 69
console.log(categoryMap);          // { navigation: [...], action: [...], ... }
console.log(Object.keys(icons));   // ['home', 'menu', 'search', ...]
```

## Architecture

```text
lombokicons/
├── src/
│   ├── icons.json          # Icon registry (paths + metadata)
│   └── css/
│       └── lombokicons.css # CSS framework source
├── dist/
│   ├── css/
│   │   ├── lombokicons.css     # Full CSS (4 KB)
│   │   └── lombokicons.min.css # Minified CSS (2.2 KB)
│   ├── js/
│   │   ├── lombokicons.mjs     # ESM module
│   │   └── lombokicons.cjs     # CJS module
│   ├── svg/
│   │   ├── line/               # 69 individual line SVGs
│   │   ├── bold/               # 69 individual bold SVGs
│   │   ├── duo/                # 69 individual duo SVGs
│   │   ├── lombokicons-line.svg  # Line sprite
│   │   ├── lombokicons-bold.svg  # Bold sprite
│   │   └── lombokicons-duo.svg   # Duo sprite
│   └── catalog.json            # Icon metadata
├── scripts/
│   ├── build.js                # Build: icons.json → dist/
│   └── test.js                 # 226 integrity tests
├── demo/
│   └── showcase.html           # Interactive showcase
└── docs/
    └── DESIGN-PHILOSOPHY.md    # Design system documentation
```

## Posting / Release Guide

| Step | Trigger | What Happens |
| ------ | --------- | -------------- |
| Merge to `main` | `release-please` | Creates release PR |
| Tag `v*` pushed | `npm-publish.yml` | Publish to npm with `--provenance --access public` |
| Tag `v*` pushed | `publish-packages.yml` | Publish to 5 GitHub Packages registries (npm GPR, Container, Maven, NuGet, RubyGems) |
| npm published | jsDelivr | CDN auto-mirrors npm |

### Manual Release

```bash
npm version patch    # or minor/major
git push --follow-tags
```

## Contributing

1. Fork the repository
2. Add icons to `src/icons.json` following the [Design Philosophy](docs/DESIGN-PHILOSOPHY.md)
3. Run `npm run build` to regenerate dist
4. Run `npm test` to verify (226 tests must pass)
5. Open a pull request

Icon contributions must follow the Diamond Canon grid and provide all three modes (line, bold_accent, duo_accent). Set accent fields to `null` when not applicable.
